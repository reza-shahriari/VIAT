## Q1. "Auto label from prompt" — end-to-end behavior (backends, frames, batch, thresholds, class mapping, NMS, confidence, threading)

### Takeaway
Auto-label (Tools > Auto Label → `AutoAnnotateDialog` → `AutoLabelWorker` QThread) is a per-frame, independent open-vocabulary detection pass over either the current frame or all frames of the loaded video/image list, with optional SAM mask refinement, class-agnostic NMS, dedup against existing labels, ignore-region suppression and (new) shadow rejection; results are saved as `BoundingBox(source='detected'|'refined', score=<model score>, verified=False)`. There is no temporal stage: the `'tracking'` strategy is a literal no-op, and no track IDs are produced.

### Inferences
- Because detector output `class_name` is the prompt text and `classes_info` is never consumed, a class whose "Extract Target" prompt differs from its name will be saved under the prompt string, and per-class dedup rules keyed by class name will not match it (inferred from main.py:223-232, 346-348, 9156-9168).
- Florence-2 and LocateAnything detections cannot be thresholded, ranked, or triaged by confidence (always 1.0), and Grounding DINO labels are free-text phrases that may not equal class names.
- Fixed class-agnostic NMS at IoU 0.5 across all classes can suppress legitimately overlapping objects of different classes (e.g. rider on bicycle) (inferred from main.py:335).
- Every frame is processed independently, so flicker (missed frames, jittering boxes, class flips) is passed straight into the labels; this matches the user's pain point that auto-labels need hand fixing.

## Q2. "Video object tracking" — how SAM 2.1 / SAM 3 / SAM2-TRT propagation, the Track Queue, object IDs/ranges, SAM 3 concept tracking, entering/leaving objects, and the fast SOT trackers work

### Takeaway
Tracking is single-object, prompt-driven propagation: the SAM Interactive dock sends one prompt (points/box/text) + a class + scope/direction to `on_sam_track_requested`, which runs SAM2.1 (Ultralytics), SAM3/3.1 (native `sam3`), SAM2-TRT, or a fast SOT tracker on the GUI thread and writes only the FIRST returned object per frame as `source='sam_tracked'` boxes, with no track ID and default score 1.0. The Track Queue batches such jobs (portable JSON) for sequential, dialog-free runs across videos. SAM 3's text-prompted multi-object video path is technically invoked when a text prompt is used, but VIAT discards object IDs/probabilities and keeps index 0; nothing handles new objects entering, objects leaving, or ID continuity.
